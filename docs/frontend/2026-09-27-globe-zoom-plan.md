## Exact behavior

1. One renderer-owned `zoom` scalar, initial/reset 1, clamp [1, 2.5]. Exact wheel rule: reject nonfinite deltaY or unknown deltaMode; normalize pixels as deltaY for mode 0, deltaY×16 for mode 1, deltaY×canvas.clientHeight for mode 2; clamp normalized delta to [-120,120]; next zoom = clamp(zoom×exp(-normalizedDelta×0.0015),1,2.5). Ignore zero delta and unchanged clamped zoom. Only ready renderer, unmodified nonzero wheel, `(hover:hover) and (pointer:fine)`, viewport ≥1000px, pointer over canvas/marker layer consumes wheel; Ctrl/Meta/browser-pinch gestures pass through. At a zoom boundary an event that cannot change zoom is not prevented. Native mobile/document and rail scrolling remain untouched. No document/window wheel handler.
2. Add native Zoom in, Zoom out, Reset view buttons, each ≥44px, labeled group, visible focus. Buttons work with keyboard, touch, and mouse. Zoom in multiplies by 1.2, Zoom out divides by 1.2, each clamped to [1,2.5]; buttons at their respective bounds are disabled. Zoom controls disabled during loading/fallback; reset restores zoom 1, longitude -100 degrees and latitude 25 degrees. A 200ms trailing debounce announces “Globe zoom N%”, where N = round(zoom×100), in the polite status region; one renderer-owned timer is cleared on new input, fallback and release. Reset/button feedback uses this same path. Button interactions preserve focus. Never hijack browser +/- shortcuts.
3. Shader and marker projection use the same zoom scalar and base-radius constant: screen globe radius = `min(width,height) * 0.47 * zoom`; shader inverse coordinates divide by this radius, CPU forward projection multiplies by it. Existing orientation remains shared. Drag sensitivity is inverse-scaled by zoom, preventing excessive movement when close. Canvas backing resolution/DPR stays unchanged; no CSS transform zoom, new textures, interpolation animation, idle rendering or postprocessing. Reduced motion is immediate just like ordinary mode.
4. Crop Earth naturally at high zoom within its existing viewport. Marker center must lie within [22,width−22]×[22,height−22] so the complete 44px hitbox fits; front-facing markers outside that safe inset are hidden and untabbable, as are rear markers. Apply viewport clipping before collision resolution. Measure each supplementary label rectangle after placement; suppress labels extending beyond the viewport or colliding with controls, never shift the geographic dot to make a label fit. If zoom/drag would hide a focused projected marker, move focus to that airport's persistent shortcut before hiding it. Keep marker-dot anchor at geographic coordinates; labels may hide for collision but never shift the dot. Preserve all six nonspatial shortcuts regardless of zoom.
5. At zoom ≥1.6, reveal at most one labeled returned metric beside each visible mapped result marker. Existing `analysisresultchange` event gains optional `airportDetails` object keyed by mapped airport; app produces it from validated rows only, using existing display formatter. Each entry contains year, status, previous flag, and a plain-text metric label/value/reason. Prefer a row metric matching `scope.metric`; for composite `congestion`/`sfo_pressure` use the first backend-returned metric without computing or ranking one. When no usable metric exists, show explicit unavailable reason rather than zero. Producer and consumer both remain live: `publishResultState` writes; globe `resultChange` reads then `updateMarkers` renders. The existing renderer-ready replay transmits current details. Text uses `textContent`, no HTML. On fallback, hide the projected marker host and all progressive labels, remove their tab stops before showing the static poster, and clear pending zoom/status work; retain the six persistent shortcuts and result panel. Keep existing result panel as complete accessible source; collision may suppress supplementary metric labels. Below threshold hide only supplementary labels, not result state or airport name. New/previous/partial result transitions replace details atomically; no stale metric may survive a new event.
